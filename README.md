# FinanzasCentral - API de Finanzas Personales

Plataforma financiera para la gestión digitalizada de presupuestos, movimientos y auditoría de registros históricos.

## Instrucciones para ejecutar el proyecto

1. Clonar el repositorio:
git clone https://github.com/jsalvoc/finanzas-personales
cd finanzas-personales

2. Crear y activar el ambiente virtual:
python -m venv ambiente
ambiente\Scripts\activate (o navegar a ambiente\Scripts\ y ejecutar .\activate)

3. Instalar dependencias:
pip install -r requirements.txt

4. Ejecutar el servidor de desarrollo:
python manage.py runserver
